# Lire un nombre binaire

## Principe

Le système binaire utilise 2 chiffres : **0 et 1**

Chaque position représente une **puissance de 2** :
- Position 0 (droite) = 2⁰ = 1
- Position 1 = 2¹ = 2
- Position 2 = 2² = 4
- Position 3 = 2³ = 8
- Position 4 = 2⁴ = 16
- etc...

## Méthode

Pour convertir un nombre binaire en décimal :
1. Prendre chaque chiffre (0 ou 1)
2. Le multiplier par la puissance de 2 de sa position
3. Additionner tous les résultats
